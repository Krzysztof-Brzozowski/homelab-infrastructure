# Infrastructure Overview

## Environment Purpose

This HomeLab environment is used for learning,
testing, and developing practical skills related to:

- Linux administration
- Docker containerisation
- Infrastructure monitoring
- Cybersecurity fundamentals
- Automation
- Self-hosted services

## Hardware Overview

Current infrastructure includes:

- Ubuntu Server host
- SSD cache storage
- HDD storage array
- USB backup drive
- Network switch and home router

## Main Services

| Service | Purpose |
|---|---|
| Uptime Kuma | Service monitoring |
| Nextcloud | Self-hosted cloud storage |
| Home Assistant | Home automation |
| Portfolio Website | Personal portfolio hosting |
| Docker | Container management |

## Storage Layout

| Mount Point | Purpose |
|---|---|
| /mnt/cache | SSD application storage |
| /mnt/storage | Main HDD data storage |
| /mnt/backup-usb | Backup storage |
