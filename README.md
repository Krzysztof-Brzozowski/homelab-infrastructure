# HomeLab Infrastructure

A practical self-hosted infrastructure project designed to develop hands-on skills in Linux administration, Docker, monitoring, networking, backups, and cybersecurity fundamentals.

## Project Overview

This HomeLab is used as a learning and testing environment for infrastructure, automation, cybersecurity, and self-hosted services. The project focuses on building a reliable small-scale server environment using real hardware and open-source tools.

## Objectives

- Build and manage a Linux-based home server environment
- Deploy and maintain Docker-based services
- Monitor service availability and system health
- Implement backup and recovery processes
- Improve security through firewall rules, access control, and hardening
- Document infrastructure decisions and lessons learned

## Current Infrastructure

- Operating System: Ubuntu Server
- Containerisation: Docker
- Monitoring: Uptime Kuma
- Web/Reverse Proxy: Nginx / Cloudflare Tunnel
- Storage: SSD cache, HDD storage, USB backup
- Services: Nextcloud, Home Assistant, Portfolio Website, Monitoring Tools

## Key Skills Demonstrated

- Linux server administration
- Docker container management
- Network and service monitoring
- Basic cybersecurity hardening
- Backup planning
- Technical documentation
- Troubleshooting and problem solving
